# First-Principles Templates

Copy-paste, fill-in templates. Hand the person whichever one fits what they're doing. They're intentionally compact so they drop cleanly into a note, a working doc, or an AI prompt. Pick the smallest one that does the job — don't hand someone all twelve.

## Quick index
- **Problem definition** — turn a fuzzy complaint into a decision-worthy statement
- **Assumption inventory** — surface what's being taken for granted (pair with `assumptions.md`)
- **Constraint analysis** — separate hard from soft constraints
- **What must be true** — the minimum set of true conditions for a plan to work
- **Root cause vs first principles** — when to dig down vs rebuild from a fundamental truth
- **Conventional wisdom challenge** — stress-test "the way it's done"
- **Solution rebuild** — generate options from fundamentals
- **Experiment design** — design the cheapest useful test
- **Executive summary** — communicate the result to decision-makers
- **Meeting facilitation** — run a working session through the discipline
- **Personal decision** — apply it to a life choice
- **First-principles journal** — build the habit; converts thinking from mood to method

## A daily 10–20 minute practice loop
For someone building the habit, this loop works on one real problem at a time:
1. Pick one real problem.
2. Write the current framing in one sentence.
3. Separate facts from assumptions.
4. Ask what must be true.
5. Identify one "hard" constraint and test whether it is really hard.
6. Generate two alternative framings.
7. Decide one small next experiment.

## One-page final checklist
For the next hard problem:
1. Write the problem in one sentence.
2. Write the current default solution in one sentence.
3. List five facts and five assumptions.
4. Circle the two assumptions that matter most.
5. Ask what must be true.
6. Mark hard vs soft constraints.
7. Generate two rebuilt options.
8. Design one cheap test.
9. Write a three-sentence executive recommendation.
10. Review what you learned after the test and update your model.
