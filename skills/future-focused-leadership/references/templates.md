# Artifact Templates

Use these exact structures when generating foresight deliverables. Default to one page per artifact. Populate with the user's real context; mark unknowns as placeholders and ask targeted follow-ups rather than inventing specifics.

## 1. One-page future signals brief

```
# Future Signals Brief: [Topic]

**Why this matters now**
**What changed in the last 30–90 days**
**Three plausible futures** (scenario families, not forecasts)
**KPI(s) affected**
**Recommended no-regret move**
**Trigger point to revisit**
**Decision owner**
```

## 2. Quarterly foresight memo

```
# Foresight Memo — [Quarter, Year]

**Executive takeaway** (2–3 sentences)
**Top five signals**
**What moved since last quarter**
**Implications** for revenue, margin, risk, talent, and speed
**Decisions recommended now**
**Decisions to defer pending trigger points**
**Small-bets update** (scale / pause / kill / redesign per bet)
```

## 3. Scenario map

```
# Scenario Map: [Focal question]

**Focal question** (a real decision, not a topic)
**Two major uncertainties** (the axes)
**Four scenario quadrants** — each with a memorable name and 2–3 sentence narrative
**"So what?" per quadrant** — what we'd do differently
**Watch points per quadrant** — observable early signals
**Robust moves** (sensible across all quadrants)
**Contingent moves** (justified only in one or two quadrants, with triggers)
```

When building scenarios: pick uncertainties that are both highly impactful AND genuinely uncertain (if it's near-certain, it's a trend to plan for, not a scenario axis). Three plausible-futures framing also works for lighter-weight use: a conservative continuation, a structural-shift case, and an acceleration case.

## 4. Risk/opportunity radar

For each force, capture:

```
| Force | Time horizon | Confidence | Upside potential | Downside risk | Owner | Current action status | Review date |
```

## 5. Force map (for analyzing an industry or strategic landscape)

For each major force, build a row:

```
| Force | Why it matters (with evidence) | Three plausible futures | Early signals to monitor | Strategic questions and small bets | Risk of ignoring it |
```

Forces to consider adapting to the user's industry: technology/AI and automation; channel and go-to-market shifts; customer behavior change; input-cost and supply volatility; regulatory shifts; new entrants and substitutes; demographic change; data/privacy/trust; labor, skills, and organizational design.

## 6. Small-bets portfolio

Each bet must specify ALL of:

```
**Bet name:**
**Hypothesis:** (what we believe and why it matters)
**Cost:**
**Time to learn:**
**Success metric:**
**Kill criteria:** (what result stops this)
**Scale trigger:** (what result justifies expansion)
**Strategic force linked:**
```

A bet without kill criteria and a scale trigger is not a bet; it's a hobby. Push back if the user omits them.

## 7. Now-to-Next decision framework

```
1. What must we keep delivering now?
2. What assumption may break next?
3. What low-cost move improves our option set?
4. What signal would justify stronger action?
5. Who decides, and by when?
```

## 8. Pre-mortem

```
# Pre-Mortem: [Initiative]

**Premise:** It is [date 12–24 months out]. The initiative has failed badly.
**Failure reasons** (brainstormed, grouped by theme: demand, execution, timing, politics, external)
**Top 3 most plausible failure paths**
**Early warning signs for each**
**Mitigations / design changes to make now**
**Watch points added to the dashboard**
```

## 9. Personal operating system (when coaching habits)

**Weekly (30 min):** scan for weak signals across technology, customer behavior, channels, regulation, and supply; write down one implication and one decision it could affect; ask "what would have to be true for this to matter commercially?"; log assumptions being made.

**Monthly:** cluster the signal log into themes; update a dashboard with signal / confidence / time horizon / KPI affected / recommended action / trigger and owner; run one 45-minute scenario conversation; review the small-bets portfolio (scale, pause, kill, redesign).

**Quarterly:** publish the one-page foresight memo; refresh scenario map and watch points; ask which annual-plan assumption now looks weakest; reallocate a small amount of time or budget accordingly.

## Formatting notes

- These templates define content structure. If the user wants a polished file (Word, slides, PDF, spreadsheet), use the appropriate document-creation skill for the format and apply these structures within it.
- Keep language commercial, not futurist. Every artifact should survive the test: "could a CFO act on this?"
