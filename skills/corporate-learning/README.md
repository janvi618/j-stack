# Corporate Learning Skill Suite

A set of skills that take anyone from *"I sort of understand this topic"* to *"I can confidently run a workshop on it for beginners and skeptics."* Topic-agnostic — works for a strategy, a new technology, a compliance change, a methodology, a culture shift, anything.

It generalizes the common "act as a learning strategist and help me master + teach this topic" brief into five reusable stages plus a front door.

## The skills

| Skill | Stage | What it produces | Triggers on |
|---|---|---|---|
| **teach-anything** | Front door / full run | The complete facilitator package + final synthesis | "help me master X so I can teach my team," a pasted end-to-end brief |
| **topic-mastery** | 1 · Understand it | A Mastery Brief: overview, mental model, core-concept table, concept map, three-level explanations | "get me up to speed on X to teach it," "the concepts are confusing" |
| **teaching-narrative** | 2 · Make it teachable | A spoken storyline (hook → old way → new way → takeaway) + example/non-example bank | "build a story for X," "find a hook," "give me examples and counter-examples" |
| **workshop-designer** | 3 · Design the session | A Workshop Plan: objectives, timed agenda, exercises, materials, pre/post comms | "design a 90-min workshop," "build a training," "make exercises" |
| **facilitation-kit** | 4 · Prep to facilitate | Objection-handling table, facilitation moves, one-page cheat sheet | "handle objections," "what will skeptics ask," "facilitator cheat sheet" |
| **teach-readiness-check** | 5 · Check readiness | A self-test (diagnostic + scenario + explain-simply) + honest gap analysis | "quiz me," "am I ready to teach this," "where are my blind spots" |

## How to use it

- **Whole journey:** start with `teach-anything`. It runs all five stages in order and ends with a workshop title and the one behavior change to drive. Best when you're starting from a broad "I need to learn and teach X" ask.
- **Just one piece:** invoke the specialist directly — e.g., you already understand the topic and only need the session designed → `workshop-designer`; you're presenting tomorrow and want to rehearse hard questions → `facilitation-kit`.
- **Natural sequence:** the outputs chain. The Mastery Brief feeds the narrative; the narrative and brief feed the workshop design; all of it feeds the facilitation kit; the readiness check tests the lot. Each skill will reuse earlier outputs if they're already in the conversation.

## Shared intake

Every skill works from the same five inputs and pulls them from the conversation before asking: **topic · audience · why-now context · the facilitator's current level · session length** (length matters most for the workshop stage). Provide what you can up front to skip the questions.

## Design notes

- Each skill is self-contained and independently installable; `teach-anything` does not depend on the others being present.
- Outputs are reusable reference documents, so the skills save them as markdown files by default rather than burying them in chat.
- The throughline across all five: lead with *why it matters*, keep language easy to say out loud, make it real for the audience's own work, and be honest about what's genuinely uncertain.
