# Session templates — agenda skeletons by length

Pick the closest skeleton and adapt the content; keep the rhythm (hook → input → activity → debrief → commitment). Times are guides — tune to your topic. The principle that matters across all of them: never more than ~10–15 minutes of straight input without an interaction, and always finish on a written commitment to act.

---

## 60 minutes (tight, single concept)

| Time | Block | Format | Purpose |
|---|---|---|---|
| 0:00–0:05 | Hook + framing | Teach | Earn attention; state what they'll leave able to do |
| 0:05–0:15 | Core idea + mental model | Teach | The one model they must hold |
| 0:15–0:18 | Quick reaction | Discuss (pairs) | Surface assumptions, give skeptics an early outlet |
| 0:18–0:38 | Main exercise | Small groups | Wrestle with the concept on a provided case |
| 0:38–0:48 | Debrief + apply-to-me | Discuss + solo | Connect to their own work |
| 0:48–0:57 | What to do differently | Teach + solo write | Behavior change + written commitment |
| 0:57–1:00 | Close | Teach | One sticky takeaway; what comes next |

*60 min = one concept, one exercise, one commitment. Don't try to cover the whole topic.*

---

## 90 minutes (a concept cluster)

| Time | Block | Format | Purpose |
|---|---|---|---|
| 0:00–0:08 | Hook + objectives | Teach | Stakes and destination |
| 0:08–0:22 | Old way → new way | Teach + discuss | The shift, with a quick room poll |
| 0:22–0:32 | Concepts (the few that matter) | Teach | Plain-language, with examples |
| 0:32–0:34 | Stretch / reset | — | Movement break |
| 0:34–0:54 | Exercise 1 (apply the concept) | Small groups | First hands-on pass |
| 0:54–1:04 | Debrief 1 | Discuss | Harvest insight, correct misreads |
| 1:04–1:24 | Exercise 2 (apply to *their* category) | Small groups | Make it real for them |
| 1:24–1:32 | Debrief 2 + commitments | Discuss + solo write | What each will do differently |
| 1:32–1:30… | Close | Teach | Takeaway + follow-up preview |

---

## Half-day (~3.5–4 hrs, deeper build + a plan)

Run as four ~45–55 min modules with two breaks. This length suits the original goal of leaving with *a plan for their own category*.

1. **Module 1 — Understand it** (~50 min): hook, why-now, old-way/new-way, core model, comprehension check.
2. *Break (10–15 min).*
3. **Module 2 — Recognize it** (~50 min): examples vs. non-examples exercise; "is this X or not?" discussion; practice spotting signals.
4. **Module 3 — Apply it** (~55 min): teams take a real case (ideally their own category) and work it end to end; structured debrief.
5. *Break (10 min).*
6. **Module 4 — Plan it** (~55 min): each participant/team drafts a concrete plan for their category using a provided one-page template; rapid-fire share-outs; peer challenge.
7. **Close** (~15 min): synthesis, one takeaway, written commitments, follow-up plan.

*For multi-session programs, treat each module above as a standalone session with its own hook and commitment, and add a 5-minute "since last time" recap at the start of each.*
