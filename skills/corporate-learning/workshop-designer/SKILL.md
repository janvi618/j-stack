# Workshop Designer — build the session

Design a session people will find engaging and *useful*, suitable for newcomers to the topic. Bias toward doing over listening: adults learn a topic by wrestling with it, not by being told about it.

## Intake

You need the **topic**, the **audience**, the **session length**, and the **goal** (what participants should be able to do afterward). Pull these from the conversation first; ask only for genuine gaps — and length is the one you must pin down, because it drives everything. If a teaching narrative or mastery brief already exists in the conversation, reuse it instead of regenerating content.

If length is unspecified and unclear from context, ask for it directly with concrete options (60 min / 90 min / half-day) rather than guessing — the agenda is unusable at the wrong scale.

## Deliverable: the Workshop Plan

Save it as a markdown file the facilitator can run from. Length-specific agenda skeletons (60 / 90 / half-day) are in `references/session-templates.md` — read it and adapt the closest one rather than building timing from scratch. Include:

- **Learning objectives** — 3–4, phrased as "by the end, participants can ___" (observable, not "understand").
- **Agenda by time block** — every block has a purpose, a format (teach / discuss / exercise / debrief), and a duration that sums to the session length. Open with a hook, alternate input and activity, never run more than ~10–15 minutes of straight talking without interaction, and end with commitment-to-action.
- **Facilitator script notes** — short cues per block ("ask this, then wait," "expect pushback here," "timebox to 4 min"), not a full script.
- **Discussion questions** — open-ended, no single right answer.
- **Small-group exercises** — see the dedicated section below.
- **Reflection prompts** — individual, quiet, written.
- **Debrief questions** — to harvest insight after each exercise.
- **Materials needed** — slides, handouts, sticky notes, templates, timer, room setup.
- **Before the workshop** — pre-work or pre-reads (keep light; people won't do much), and what to prepare.
- **After the workshop** — the follow-up send: summary, one-page recap, the commitment they made, next step.

## Exercises (3–5, fully specified)

For each exercise, give: **Name · Purpose · Instructions (step by step) · Time needed · Group format (solo / pairs / small groups / whole room) · Materials · Expected output · Debrief questions · What the facilitator should watch for** (common failure modes, signs of confusion, when to intervene vs. let them struggle).

At least one exercise must have participants **apply the topic to their own work** — their category, their product, their decisions. This "make it real for *me*" activity is what converts a session from interesting to actionable; protect time for it.

## Design principles

- **Time math is honest.** Blocks sum to the total. Build in buffer and transitions; sessions always run long.
- **Skeptics need an early win.** Give doubters something concrete to react to in the first third, before they've decided to disengage.
- **Beginners need safety.** Use small groups before whole-room share-outs so no one is exposed cold.
- **One takeaway, not ten.** A session that lands one behavior change beats one that sprays twelve concepts.
- **End on commitment.** The last block should produce a written "what I'll do differently," not a thank-you slide.
